# 📦 Industrial Hub Assets CDN

Репозиторий статических изображений предметов и скинов Rust для приложения **Industrial Hub**.

## Структура
- `items/` — файлы изображений предметов и скинов (`.png`, `.jpg`, `.webp`).
- `manifest.json` — метаданные всех файлов с их размерами и SHA-256 хешами для дифференциальной синхронизации.
- `generate-manifest.js` — скрипт автоматического пересчета хешей и генерации `manifest.json`.

## Как добавить или обновить изображения
1. Поместите новые или обновленные изображения в папку `items/`.
2. Запустите генерацию манифеста:
   ```bash
   node generate-manifest.js
   ```
3. Зафиксируйте и отправьте изменения:
   ```bash
   git add .
   git commit -m "Add new items"
   git push
   ```
Клиенты Industrial Hub автоматически скачают только новые или измененные изображения при следующем запуске или по сигналу сервера.
