# 🖼️ Инструкция: Как добавлять и обновлять картинки предметов

Благодаря выносу картинок в отдельный репозиторий [industrial-hub-assets](https://github.com/kozhaki-vik/industrial-hub-assets), вам больше **не нужно пересобирать саму программу** и выпускать новый `.exe` релиз при добавлении новых скинов или предметов Rust!

Все клиенты автоматически скачивают только новые или измененные картинки через CDN GitHub.

---

## 📁 Где находятся файлы
Локальная папка репозитория ассетов на вашем ПК:
`C:\Users\dimav\source\repos\industrial-hub-assets`

Внутри находятся:
* `items/` — папка со всеми картинками предметов (форматы `.png`, `.jpg`, `.webp`). Название файла должно строго соответствовать `shortname` предмета (например: `rifle.ak.png`, `ammo.rifle.png`).
* `manifest.json` — реестр всех файлов с их размерами и SHA-256 хешами.
* `generate-manifest.js` — скрипт, который автоматически пересчитывает хеши всех файлов и обновляет `manifest.json`.

---

## 🛠️ Пошаговый процесс добавления или изменения картинок

### Шаг 1: Добавьте файлы картинок
Скопируйте новые картинки в папку:
`c:\Users\dimav\source\repos\industrial-hub-assets\items\`

> [!IMPORTANT]
> **Имя файла:** Имя файла должно быть в формате `<shortname>.png` (например, `pistol.revolver.png`). Разрешены только английские буквы, цифры, точки, дефисы и подчеркивания.

---

### Шаг 2: Пересчитайте манифест (хеши)
Откройте PowerShell или командную строку в папке репозитория и запустите команду:
```powershell
cd "C:\Users\dimav\source\repos\industrial-hub-assets"
node generate-manifest.js
```
Скрипт выведет:
`[Manifest Generator] Successfully generated manifest.json with XXXX assets.`

---

### Шаг 3: Отправьте изменения на GitHub
Выполните стандартные команды git:
```powershell
git add .
git commit -m "Добавлены новые предметы Rust"
git push origin main
```

---

### Шаг 4 (Опционально): Мгновенное оповещение всех запущенных клиентов
Если вы хотите, чтобы клиенты, у которых приложение **уже открыто прямо сейчас**, моментально скачали новые картинки без перезапуска программы:

Выполните один POST-запрос на сервер (через PowerShell или браузер/Postman):
```powershell
Invoke-RestMethod -Uri "https://industrial-hub.duckdns.org/api/assets/notify" -Method Post
```
Сервер отправит сигнал по WebSocket всем подключенным клиентам, и они в фоновом режиме докачают новые картинки за несколько секунд.

*(Если этот шаг пропустить, клиенты в любом случае проверят и скачают новые картинки автоматически при своем следующем запуске).*

## 🛡️ Безопасность и хранение на компьютере пользователя
1. **Где хранятся скачанные картинки у пользователя:**  
   `%APPDATA%\industrial-hub\cache\items\`
2. **Дифференциальная загрузка (Delta):**  
   Клиент никогда не качает всю базу заново. Сверяются SHA-256 хеши: если картинка уже есть и хеш совпадает, она пропускается. Если картинка удалена из репозитория, клиент удаляет её из локального кэша.
3. **Защита от Path Traversal:**  
   Имена файлов фильтруются по белому списку регулярных выражений, что исключает запись файлов за пределы папки кэша.
